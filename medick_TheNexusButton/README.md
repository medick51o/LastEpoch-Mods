# A Terrible Button: The Nexus Button — v0.1.0

*it's a button. a beautiful button.* A [MelonLoader](https://melonwiki.xyz/) mod for **Last Epoch**.

One click opens the game's own travel menu (maps, Monolith timelines, Activities and Factions). The button is cloned
from EHG's THE NEXUS button and sits right above the ACTIVITIES tab, matching the panel tabs. A shortcut: fewer steps,
quicker getting around.

- Optional **N** hotkey (off by default)
- **Show Nexus Button** toggle for hotkey-only players
- Live X/Y position sliders and Reset in Settings → A Terrible Button
- Follows the game's UI scale (tested 16:9 and 21:9)

**Install:** MelonLoader 0.7.3, then drop `medick_A_Terrible_Button.dll` into `Last Epoch/Mods/`. Zip in `release/`.
