-----------------
Class:  CosmeticsManager  (namespace Il2Cpp, from Il2CppLE.dll)

Game signature (Il2Cpp interop):

This is the ONLY method the game calls to check which cosmetics the player owns.
It normally makes an async backend/server call to get the player's purchased IDs.

2. THE PATCH — HOW IT WORKS
----------------------------
File: LastEpoch_Hud.Scripts.Mods.Cosmetics.Cosmetics_Offline
Patch type: HarmonyPrefix on CosmeticsManager.GetOwnedCosmetics

What it does:
  1. Uses Resources.FindObjectsOfTypeAll<Cosmetic>() to find EVERY cosmetic
     ScriptableObject loaded in memory (all skins, pets, portals, titles, etc.)
  2. Collects each one's BackendID (a string like "cosmetic_armor_set_01")
     into a static List<string>, deduplicating.
  3. Sets __result to a UniTask wrapping that complete list.
  4. Returns false — skipping the original method entirely.

Effect: The game thinks the player owns every cosmetic that exists in the game data.
No server call is ever made. Works offline.

3. FULL DECOMPILED PATCH CODE
-----------------------------
[HarmonyPatch(typeof(CosmeticsManager), "GetOwnedCosmetics")]
public class CosmeticsManager_GetOwnedCosmetics
{
    [HarmonyPrefix]
    private static bool Prefix(ref CosmeticsManager __instance, ref UniTask<List<string>> __result)
    {
        if (list_id.IsNullOrDestroyed())
        {
            List<Cosmetic> list = new List<Cosmetic>();
            foreach (Cosmetic item in Resources.FindObjectsOfTypeAll<Cosmetic>())
            {
                list.Add(item);
            }
            if (!list.IsNullOrDestroyed())
            {
                list_id = new List<string>();
                foreach (Cosmetic item2 in list)
                {
                    if (!list_id.Contains(item2.BackendID))
                    {
                        list_id.Add(item2.BackendID);
                    }
                }
            }
        }
        __result = new UniTask<List<string>>(list_id);
        return false;
    }
}
